# Arrays - Data Structures in C++

This folder contains all basic operations of Arrays in C++.

## Files Included

1.  **2D_array_input_output.cpp** - Taking input and displaying 2D array.
2.  **array_traversal.cpp** - Traversing and printing array elements.
3.  **arrays_insertion.cpp** - Inserting an element at a specific position.
4.  **array_deletion.cpp** - Deleting an element from array.
5.  **array_searching.cpp** - Linear Search implementation.
6.  **binary_search.cpp** - Binary Search (for sorted array).
7.  **bubble_sort_ascending_.cpp** - Sorting in increasing order.
8.  **bubble_sort_descending.cpp** - Sorting in decreasing order.
9.  **selection_sort.cpp** - Selection Sort implementation.

## Concepts Covered
- Traversal, Insertion, Deletion
- Searching & Sorting
- 1D and 2D Arrays

Language: C++
